# Security policy

This is a game about people who find the way in, so it would be a poor joke if the game
itself had one nobody meant to leave open. If you have found a real one, we would like to
hear about it before anyone else does.

## What counts

The attacks inside the worlds are fiction: the diverted traffic, the borrowed mailbox and the
raised alarm are words in a text file and touch nothing real. A security issue lives in the
machinery instead, where loading a world, restoring a save, or running the local map editor
could be made to run code, read files it should not, or otherwise harm the machine it runs
on. The editor having no login is not one of these: it is a local, single-author tool, and
says so.

## How to report

Please do not open a public issue. Reach the maintainers privately through
https://tymyrddin.dev/contact/, or use the repository's Security tab and choose "Report a
vulnerability". Say what you did, what happened, the version or commit you were on, and how to
reproduce it.

We are a small project, so expect an answer in days rather than minutes, and no bounty beyond
real thanks and, if you want it, the credit for the find. We will see a fix out before
anything is said in public.
